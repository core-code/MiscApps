Marathon Open Source Saved Game Editor(MOSSGE)Source codeAbout:Included in this archive is the complete CodeWarrior Pro 5 source for the Marathon 2 and Infinity saved game editor MOSSGE. You require to comment and uncomment one obvious line to compile for Carbon or Classsic enviornments. You are also free to modify, redistribute and make (and distribute) binaries from this source in any form you like. In fact you can do anything you want to it. If you actually make it more useful then please send me your changes so that they can be distributed in future versions of this archive.MOSSGEBy Craig Miller <jedric@geocities.com>
