Marathon Infinity unofficial saved game specsBy Craig Miller <www.geocities.com/TimesSquare/Labyrinth/3691>If you wish to add to this file then email me a copy so that I can add it to the document on my page.Player data follows ASCII text 'plyr'all data is 2 bytesbytes after end of 'plyr' - item76 - Health78 - Oxygen108 - .44 Magnum guns110 - .44 Magnum ammo112 - Fusion guns
